# go-project on gokit v0.6.0

Branch: `feat/gokit-v0.6.0` (from `main` at a0de094).

## Goal

Move to gokit v0.6.0, which uses AssetPulse's response format:
- success: `{"success":true,"data":...}`, with `data` left out when empty
- error: `{"success":false,"error":{"code":"ERR_...","message":"..."}}`

go-project and AssetPulse then share one format. go-project has no external clients, so its messages may change.

## Task 1 (one task; the parts are tightly coupled)

1. **Dependency.** `go get github.com/piresc/gokit@v0.6.0`, then `go mod tidy`. No `replace` directive.
2. **Call sites.** Every `response.Error(w, status, msg)` becomes `response.Error(w, status, code, message)`. Use gokit's `response.Code*` constants where one fits. Messages are sentence case, like gokit and AssetPulse.
   - **user-service** matches AssetPulse's USS exactly (it's a port of it):

     | Status | Code | Message |
     |---|---|---|
     | 401 | `ERR_INVALID_TOKEN` | `Invalid token` |
     | 401 | `ERR_TOKEN_EXPIRED` | `Token expired` |
     | 401 | `ERR_INVALID_AUDIENCE` | `Invalid token audience` |
     | 401 | `ERR_REFRESH_EXPIRED` | `Refresh token expired` |
     | 401 | `ERR_INVALID_REFRESH` | `Invalid refresh token` |
     | 404 | `ERR_NOT_FOUND` | `User not found` |
     | 400 | `ERR_INVALID_INPUT` | the existing invalid-body / invalid-input message, sentence case |
     | 500 | `ERR_INTERNAL` | `Internal server error` |
     | 401 | `ERR_UNAUTHORIZED` | `Authentication required` |

     Define the service-specific codes as constants in `internal/user/handler/http/errors.go`.
   - **asset-service:**

     | Case | Status | Code | Message |
     |---|---|---|---|
     | not authenticated | 401 | `ERR_UNAUTHORIZED` | `Authentication required` |
     | invalid input | 400 | `ERR_INVALID_INPUT` | `Invalid input` |
     | holding not found | 404 | `ERR_NOT_FOUND` | `Holding not found` |
     | portfolio not found | 404 | `ERR_NOT_FOUND` | `Portfolio not found` |
     | too many holdings | 409 | `ERR_TOO_MANY_HOLDINGS` (service constant) | `Too many holdings` |
     | prices unavailable | 503 | `ERR_SERVICE_UNAVAILABLE` | `Prices unavailable` |
     | server error | 500 | `ERR_INTERNAL` | `Internal server error` |

   - **price-service:**
     - 400 `ERR_INVALID_INPUT`: `Symbols is required`, `Too many symbols`, `Invalid symbol`
     - 500 `ERR_INTERNAL`: `Internal server error`
3. **`pkg/platform/httpclient.go`.**
   - `decodeJSONBody` understands the new envelope. With `success:false`, it returns an error carrying the code and message (error text such as `API error: ERR_X: msg`), and the body is never decoded into `out`.
   - A 2xx `success:true` body unwraps `data`. A missing `data` leaves `out` untouched.
   - Plain JSON without `success` (e.g. the market API) decodes as-is.
   - Drop the old `status`-envelope handling; nothing in the stack produces it any more.
   - Update the tests, using gokit's `response.Success`/`response.Error` to build bodies. Keep the 4xx/5xx breaker behaviour unchanged.
4. **Tests.** Update every handler test that asserts on bodies or messages to the new shape and texts. `internal/asset/gateway/price/price_test.go` builds its body with the new `response.Success`.
5. **`deploy/e2e_test.sh`.**
   - `.status` checks become `.success == true/false`.
   - `.error` checks become `.error.code` (preferred) or `.error.message`. The logout check expects `ERR_TOKEN_REVOKED`.
   - Empty-list checks must allow a missing `data`: use `(.data // []) | length`.
   - Keep the number of checks at 46 or more.
6. **Docs.** ARCHITECTURE.md / README / AGENTS.md describe the envelope and the `response.Error(w, status, code, message)` rule. Fix any example that still shows the old shape.

### Plan-review rulings (binding; they override the text above where the two differ)

1. **`pkg/platform/httpclient.go` on 4xx/5xx.**
   - Inside `breaker.Execute`, a status of 400 or above now reads the body, capped at `maxResponseBytes`. It returns gokit's exported `*httpclient.APIError{StatusCode, Code, Message}`.
   - When the body isn't an envelope, `Message` is `http.StatusText(status)`.
   - Drop the local `statusError`. `isSuccessful` becomes `errors.As(err, &apiErr) && apiErr.StatusCode < 500`; context cancellation stays as it is.
   - A 2xx `success:false` body also returns `*httpclient.APIError`.
   - Do NOT call gokit's `GetJSON`: it has no size cap, and its non-envelope errors are untyped.
   - Tests: a 400 envelope's code and message reach the caller (`errors.As`). The existing 4xx/5xx breaker tests pass unchanged.
